# 截图目录

本目录用于保存作业需要的截图。

建议命名：

- `modelscope_login.png`：ModelScope 登录或资源页面
- `cpu_notebook_started.png`：CPU Notebook 启动成功页面
- `terminal_opened.png`：Terminal 打开页面
- `pip_install_success.png`：依赖安装成功页面
- `clone_models_success.png`：模型仓库克隆成功页面
- `clone_project_success.png`：本 GitHub 项目克隆成功页面
- `qwen_q1.png` 至 `qwen_q5.png`：Qwen 测试结果
- `chatglm3_q1.png` 至 `chatglm3_q5.png`：ChatGLM3 测试结果
- `baichuan_q1.png` 至 `baichuan_q5.png`：Baichuan 测试结果
- `github_homepage.png`：GitHub 仓库首页
- `results_or_report.png`：GitHub 中 results 或 report 页面

截图清单详见 `docs/screenshot_checklist.md`。
